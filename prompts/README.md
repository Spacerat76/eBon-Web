# Prompts fuer inkrementelle KI-Umsetzung

Dieser Ordner enthaelt vorbereitete Prompts, um das Projekt Schritt fuer Schritt per KI-Agent umsetzen zu lassen.

## Verwendung

1. Starte mit `phase-01-devcontainer.md`.
2. Kopiere den Prompt komplett in den KI-Agenten.
3. Lasse genau diese Phase umsetzen.
4. Teste das Ergebnis lokal.
5. Behebe eventuelle Fehler mit `fix-current-phase.md`.
6. Gehe erst danach zur naechsten Phase.

## Reihenfolge

1. `phase-01-devcontainer.md`
2. `phase-02-backend-skeleton.md`
3. `phase-03-database-migrations.md`
4. `phase-04-paperless-sync.md`
5. `phase-05-parser-corpus.md`
6. `phase-06-categorization.md`
7. `phase-07-rest-api-contracts.md`
8. `phase-08-frontend-shell.md`
9. `phase-09-receipts-ui.md`
10. `phase-10-search-reports-settings.md`
11. `phase-11-backup-restore.md`
12. `phase-12-real-integration-hardening.md`

Bei limitiertem KI-Kontingent: Nach jeder Phase stoppen, selbst pruefen, dann erst weiter.
